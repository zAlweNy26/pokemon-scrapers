# Game text to review — 2026-11-10

Since 2026-11-10 every game text comes from the games themselves, through Poké Corpus
("Game text only" in CLAUDE.md). The disagreements this file tracked between
Bulbapedia's transcriptions and PokéAPI are settled by that rule: the corpus wins.
What is left to review with Dany is below; remove a section or row once it is settled.

## 1. Gaps the games may fill

- **Forms the games give no label.** HOME has entries for Totem Pokémon, Partner Pikachu and
  Eevee, female Frillish/Jellicent/Unfezant, Scatterbug's patterns, Ash-Greninja and a few more
  (about 185 rows over Sun/Moon to Legends Z-A), but no form label to file them under, so the
  build leaves them out and prints them. Their names (`form.name_*`) keep PokéAPI's composition
  for the same reason ("Bug Arceus", "Totem Alolan Raticate" are no game's words).
- **Two forms HOME labels alike** in one game: Zygarde's two "10% Forme", Urshifu's two
  "Gigantamax", Darmanitan's two "Zen Mode", Genesect's drives in Legends Z-A. The first one's
  entry is kept, the others are printed by the build.
- **Pokédex names no game shows on their own**: Kanto, Original/Updated Johto, Platinum's Sinnoh,
  Let's Go Kanto, Hisui, Champions. Only `en` is filled, with PokéAPI's name (awaiting Dany's OK,
  see CLAUDE.md). Sword/Shield labels its Galar Pokédex just "Pokédex", which is what we ship.
- **Game names** (`game.name_*`, PokéAPI's, non-game) still lack Chinese for the games never sold
  in Chinese, Korean for The Teal Mask/The Indigo Disk, Japanese for Mega Dimension, and every
  language but English for Champions. The games write "Pokémon Champions" in Latin letters everywhere.
- **The Shadow type** has no Spanish name: Colosseum and XD show "?".

## 2. Rendering judgments

- **Game Boy hyphens at a line's end** (`unsplitWords` in `src/scraper/dex-entries.ts`): a word
  split by the narrow text box loses its hyphen, a compound keeps it, decided by how the games
  spell the word elsewhere. Ambiguous ones went the games' way, not always Bulbapedia's or
  PokéAPI's: "over-hunted" (both sources: "overhunted"), "hot-headed" (PokéAPI: "hotheaded").
- **HOME's text for languages the original game never shipped**: FireRed/LeafGreen in Korean
  and Chinese, X/Y and Omega Ruby/Alpha Sapphire in Chinese. HOME shows them, so they ship.

extractions join differently; some are a real difference (Pearl's "alpha waves", which PokéAPI
lost a character of; Ruby/Sapphire's Paras, whose 1.0 text PokéAPI has).
